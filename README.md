Taschenrechner

Ein einfacher Taschenrechner in C++.

Funktionen

Addition (+)

Subtraktion (-)

Multiplikation (*)

Division (/)

Mehrfache Berechnungen ohne Neustart

Schutz gegen Division durch Null

Beispiel

Eingabe:

4 + 5 

Ausgabe:

Ergebnis: 9
